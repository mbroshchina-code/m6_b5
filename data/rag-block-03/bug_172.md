# Баг №172: БС: Длинные чеки фискализируются несколько раз из интеграционного приложения

Номер бага: 172
Дата создания: 2026-09-08
Тема: БС::Кассовый чек
Статус: Создана
Код статуса: CREATED
Влияние: Не блокирует работу

## Описание

При отправке чека из интеграционного приложения для фискализации с количеством товаров более 100 наблюдается бесконечная фискализация. Печатается без остановки бумажный новый чек и отправляется его электронная копия в ОФД.

## Временное решение

1. Проводить чек не более 50-ти позиций (максимально 100)
