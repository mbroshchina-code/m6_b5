# Баг №167: БC: В чеке вместо символа № в Место расчетов печатается символ $

Номер бага: 167
Дата создания: 2026-05-08
Тема: БС::Кассовый чек
Статус: Закрыто
Код статуса: Закрыто
Влияние: Возможны штрафы

## Описание

Если при регистрации/перерегистрации аппарата добавить символ № в поле Место расчетов, то при печати бумажного чека и его электронной форме будет отображаться символ $. При указании символа в начале текста он заменяется при печати на символ #

## Временное решение

Указывать символ N вместо №
