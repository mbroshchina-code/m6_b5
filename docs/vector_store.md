### 2. DatetimeRange: баги за последние 30 дней

`created_at` означает дату создания бага.
Поскольку исходные данные содержат дату без времени,
она сохранена как полночь UTC.

```python
from datetime import datetime, timedelta, timezone

from qdrant_client.models import DatetimeRange, FieldCondition, Filter

today = datetime.now(timezone.utc).replace(
    hour=0,
    minute=0,
    second=0,
    microsecond=0,
)
cutoff = today - timedelta(days=30)

query_filter = Filter(
    must=[
        FieldCondition(
            key="created_at",
            range=DatetimeRange(gte=cutoff),
        ),
    ],
)
```

В этом прогоне граница фильтра:
`2026-08-17T00:00:00Z`.

### 3. Must + must_not: тема без закрытых и решённых багов

Для этого примера исключаются значения `status`:
`Закрыто` и `SUCCESS`, присутствующие в исходной базе.

```python
from qdrant_client.models import (
    FieldCondition,
    Filter,
    MatchAny,
    MatchValue,
)

query_filter = Filter(
    must=[
        FieldCondition(
            key="category",
            match=MatchValue(value="БС::Кассовый чек"),
        ),
    ],
    must_not=[
        FieldCondition(
            key="status",
            match=MatchAny(any=["Закрыто", "SUCCESS"]),
        ),
    ],
)
```

| Место | Номер бага | Статус | Score |
|---|---|---|---|
| 1 | 135 | CREATED | 0.6197 |
| 2 | 162 | BACKLOG | 0.4696 |
| 3 | 172 | CREATED | 0.4327 |

Время запроса: 131.82 мс.

Все результаты относятся к нужной теме.
Закрытый баг №167 исключён по статусу.
Совпадение выдачи с фильтром по дате относится к этому примеру:
условия двух фильтров различаются.

Для единичных векторов cosine similarity равна скалярному произведению.
Поэтому математически обе метрики дают одинаковое ранжирование.
Округление чисел может влиять на порядок почти равных результатов.

В рабочей коллекции оставляю COSINE: для поиска багов сравниваю направления векторов, а их длину не использую как признак релевантности.
Сохранённые векторы прочитаны из COSINE-коллекции, где Qdrant нормализует их; эксперимент проверяет именно эти сохранённые векторы.

HNSW: m=16, ef_construct=100. Для базы из 103 коротких документов оставлены умеренные параметры без дополнительного увеличения расхода памяти и времени построения графа.

После эксперимента обе созданные учебные коллекции удалены.
Рабочая коллекция `documents` сохранена.

## Проверки загрузки и жизненного цикла

- Первый запуск загрузчика: 0 → 103 точки.
- Повторный запуск: 103 → 103 точки, дублей нет.
- При запуске FastAPI создаётся один экземпляр VectorStore.
- ensure_collection вызывается в lifespan.
- При остановке FastAPI клиент Qdrant закрывается.
- Коллекция размерности 1536 отклоняется при ожидаемой размерности 1537.
- Вектор длины 2 отклоняется перед загрузкой в коллекцию размерности 1536.
- upsert, search и ensure_collection проверены ручными прогонами
  с реальным сервером Qdrant.
