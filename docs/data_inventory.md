# Инвентаризация данных — Б5.5

## Рабочий источник

Единственный исходный источник базы багов: data/bugs_database.json.

Формат и содержимое исходного JSON не изменяются ради многоформатного эксперимента.

## Учебный многоформатный корпус

Расположение: data/training_bugs/.

Корпус автоматически экспортирован из 50 разных карточек исходной базы скриптом scripts/export_training_corpus.py.

| Формат | Количество документов |
|---|---:|
| Markdown | 25 |
| PDF | 25 |
| Всего | 50 |

Общий размер документов: 1268122 байт.

Размер рассчитан по MD/PDF, без служебного export_manifest.json.

Одна карточка представлена только в одном формате.
PDF содержат текст, а не сканы.

Экспорт предназначен для проверки чтения разных форматов
и идемпотентной индексации. Это не вторая база,
которую нужно поддерживать вручную.

## Разделение корпусов

- bugs_database.json — исходная база;
- training_bugs/ — учебный экспорт для Б5.5;
- rag-block-03/ — прежний учебный корпус Б5.3.

Эти представления нельзя без дедупликации объединять как независимые баги в одной рабочей коллекции.

export_manifest.json — служебный файл и не индексируется.

## Метаданные документов

Дата создания бага берётся из исходного JSON.
Время изменения экспортированного файла хранится отдельно
и не используется для определения свежести бага.

В исходных карточках нет сведений об авторе,
поэтому метаданные author для этого корпуса не заполняются.

## Ограничения проверки

Учебные PDF сгенерированы из JSON.
Их успешное чтение не доказывает поддержку произвольных PDF со сложной вёрсткой или сканов, требующих OCR.

Корпус проиндексирован в ingest_training_bugs: 50 файлов, 91 чанк.
Повторный запуск пропускает все 50 неизменённых файлов без дублей.

- Категории: training_bugs.
