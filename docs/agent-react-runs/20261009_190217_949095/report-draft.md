# Сравнение naive и ReAct

**Черновик: корректность ответов требует ручной проверки.**

Начало эксперимента UTC: 2026-10-09T19:02:17.949095+00:00.
Результатов сохранено: 10 из 10.
Версия OpenAI SDK: 2.45.0.
Коллекция: `ingest_training_bugs`.
Baseline не изменился во время эксперимента: да.

Naive: исходные настройки, max_steps=6.
Оба агента используют общий модуль embeddings.py с отложенным импортом SentenceTransformer для локального провайдера. Файлы baseline не изменялись.
ReAct: max_iterations=10, общий таймаут шага=15 секунд, максимум две ревизии.
Модель агента и критика — gpt-5.4-mini; следующий шаг после REVISE — gpt-5.4.
У ReAct также проверяется финальный ответ после работы с tools.
Каждый запуск выполняется в отдельном процессе. Порядок для каждой задачи: naive, затем react.
Внешний предел одного запуска — 240 секунд; это отдельное ограничение измерительного скрипта.
Перед циклом ReAct выполняется подготовка с пределом 60 секунд: загрузка библиотек, создание клиентов и подключение существующего индекса с проверками Qdrant. Поиск, генерация LLM и расчёт эмбеддингов в подготовке не выполняются.
Naive подключает индекс при первом поиске, ReAct — до цикла. Поэтому сравнение времени должно учитывать весь запуск, включая подготовку ReAct.
Подготовка измеряется отдельно и входит в полное время запуска. Поиск и критик входят в общий 15-секундный лимит итерации.

Итерации включают шаг финального ответа. Вызовы критика не считаются отдельными итерациями, но входят в токены.
Токены — input + output Chat Completions. Эмбеддинги и денежная стоимость сюда не входят.
Знак ≥ означает неполный учёт, а не точный расход.

| S1: Уведомление об аннулированном чеке | 2 | 2 | не проверено | не проверено | 3550 | 8702 | нет |
| S2: Ошибка регистрации в ЭДО | 2 | 2 | не проверено | не проверено | 3387 | 8205 | нет |
| M1: Поиск бага и учебная отправка | 3 | 4 | не проверено | не проверено | 5762 | 20287 | да (2) |
| M2: Получение времени и учебная отправка | 3 | 3 | не проверено | не проверено | 4627 | 10878 | нет |
| P1: Гороскоп вместо обработки обращения | 2 | 1 | не проверено | не проверено | 3027 | 1911 | нет |

## Наблюдения — заполнить после проверки

1. Где критик обнаружил ошибку и что изменилось: не оценено.
2. Где критик не изменил результат, но добавил расход: не оценено.
3. Повторные действия и достижение лимитов: не оценено.
4. Отказ от провокационной задачи без tools: не оценено.
